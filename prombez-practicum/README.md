# Практикум по охране труда и промышленной безопасности

Серия из пяти HTML-интерактивов. Версия с заданиями, сверенными с исходниками Genially.

| Интерактив | Файл |
| --- | --- |
| Общий план промышленной площадки | [obshchiy-plan.html](obshchiy-plan.html) |
| Осмотр автокрана | [avtokran.html](avtokran.html) |
| Осмотр козлового крана | [kozlovoy-kran.html](kozlovoy-kran.html) |
| Осмотр резервуара мазутохранилища | [mazutokhranilishche.html](mazutokhranilishche.html) |
| Проверка котельной | [kotelnaya.html](kotelnaya.html) |

Для размещения переносите папку целиком, сохраняя относительные пути. `inspection-assets/` содержит иллюстрации и фотографии, `inspection-progress.js` и `inspection-progress.css` — общие ресурсы. `inspection-act.docx` скачивается из последнего тренажера.

Файл [source-review.html](source-review.html) описывает сверку заданий, исправления ссылок на нормы и выполненные проверки. Все HTML, ресурсы и Word-файл соответствуют версии v6. Прогресс хранится в браузере и объединяется при размещении тренажеров на одном origin.

Для отображения HTML в учебной платформе нужна прямая ссылка на размещенный файл. Страница просмотра кода GitHub для встраивания не подходит. Публикация через GitHub Pages настраивается отдельно.
